# Agents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Named, specialised CLI agents (folder + conversation + optional instructions/sources) that can be created blank, from a session, from a conversation (fork / fork+compact / distill) or by duplication, opened as a normal terminal, and run headlessly through one shared runner that routines (1.7.0) and messaging (1.8.0) will reuse.

**Architecture:** New `src/agents/` module (`Agent` types, `AgentStore` over `JsonStore`, `ClaudeRunner` Strategy-free single class that spawns the CLI, `ConversationForker`, `AgentService` façade) wired in `src/runtime.ts`, exposed by `src/http/routes/agents.ts`, used by a new vanilla-JS sidebar module. agenv only starts the developer's own CLI in the agent's folder: no connectors, no stored credentials.

**Tech Stack:** TypeScript (strict, CommonJS → `dist/`), Express, node:test, a fake `claude` node script, vanilla JS ES modules, playwright-core for the one e2e flow.

**Spec:** `docs/superpowers/specs/2026-10-17-agents-design.md` (routines amendment: `docs/superpowers/specs/2026-10-17-routines-design.md`).

## Global Constraints

- Execute on a new branch `feat/agents` cut from `main`; bring the two spec commits over first (`git cherry-pick 38ee3e3 438d59c`). Leave the untracked `lib/` and `.clips/` alone (`lib/cron.js` belongs to the routines plan).
- Agent `name`: unique, 1–48 chars, letters/digits/`-`/`_` only (it is the future messaging address).
- Store file `~/.agenv-agents.enc`; runs always start with `cwd = agent.cwd`; default permission `acceptEdits`.
- Creation runs: `--max-budget-usd 1`, timeout 5 min; distill uses `--permission-mode plan`.
- Distill outputs: `<cwd>/.claude/agenv-briefings/<name>.md` (briefing) or `<cwd>/.claude/skills/<name>/SKILL.md` (front-matter `name`, `description`).
- Fork/compact threshold hint: transcript ≥ 400 KB ≈ 100k tokens suggests compacting.
- The source conversation is never altered; one process writes a conversation at a time.
- Claude binary = `process.env.AGENV_CLAUDE_BIN || "claude"`; if it ends in `.js`, spawn `process.execPath [bin, ...args]` (Windows cannot exec `.js`). Headless prompt is passed as the final argv item (needed for `/compact`), stdin `ignore`.
- No automated test calls the real Claude or spends money. No publishing, tagging or pushing without the user's explicit approval.
- Keep green: `npm test`, `node scripts/golden-master.js <pre-ts entry> <entry>` (110 calls), `node scripts/compat-check.js`. New routes are additive; `test/routes.inventory.json` is baseline-generated and stays untouched.
- Code style: match `src/` (small classes, constructor-injected deps, `HttpError`, no comments that restate code), CRLF handled by git.

## Review Focus

1. **Name collisions** — `Foo` vs `foo`, duplicate of a duplicate (`x-copy`, `x-copy-2`), and rename onto an existing name: reject/auto-suffix, never two agents with one address (Task 1).
2. **Failed creation leaves debris** — fork or distill that fails, times out or exceeds budget must leave no agent record, no briefing/skill file, and the source conversation untouched (Tasks 3–4).
3. **Distill writing outside the folder or over a developer's file** — a name can't escape `cwd`; an existing briefing/skill file is not overwritten without explicit confirmation (Task 3).
4. **Missing/changed folder or a conversation open in a terminal at run time** — run refuses with a clear reason and spawns nothing; two runs on one conversation never overlap (Task 4).
5. **Prompts and ids that look like flags or paths** — a prompt beginning with `/` or `-`, a conversation id with odd characters: passed as data, never as options or a Windows path (Tasks 2, 5).
